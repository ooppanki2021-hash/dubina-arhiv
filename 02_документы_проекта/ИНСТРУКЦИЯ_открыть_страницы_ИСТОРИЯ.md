# Как открыть 6 страниц для поиска

> ## ⛔ ПРИМЕНЯТЬ ПОКА НЕ НАДО — 14.09.2026
>
> Проверка содержания страниц показала: открывать их рано. На 14 страницах дублируется шаблонный хвост, а на `/sredstva-ot-zapaha/` лежит текст, который вообще нельзя публиковать (себестоимость, сравнение с хурмой, обрывок черновика).
>
> **Сначала — `КАРТА_КОНТЕНТА.md`.** Техническая часть этой инструкции верна и пригодится позже, когда тексты будут готовы. Тогда открывать по 2–3 страницы по мере готовности, а не все шесть разом.

*Пошагово. Делается через сайт GitHub в браузере, ничего устанавливать не нужно. Время — около часа.*

---

## Что вообще происходит

На каждой закрытой странице стоит **одна строка в самом верху файла**:

```html
<meta name="robots" content="noindex, nofollow">
```

По-русски она говорит поисковику: *«эту страницу не бери в поиск и по ссылкам с неё не ходи»*.

**Открыть страницу = удалить эту строку.** Всё. Больше ничего в файле трогать не нужно.

Потом добавляем адрес страницы в `sitemap.xml` (список того, что показываем Яндексу) и просим переобход в Вебмастере.

# ШАГ 1. Убрать noindex (6 раз, по 2 минуты)

Делаешь одно и то же для каждой из шести страниц. Показываю на примере первой.

1. Открой в браузере:
   **github.com/ooppanki2021-hash/zapahstarosti**

2. Зайди в папку `zapah-v-kvartire` → нажми на файл `index.html`

3. Справа сверху нажми **карандашик** (Edit this file)

4. Найди в первых строках файла:
   ```html
   <meta name="robots" content="noindex, nofollow">
   ```

5. **Удали всю эту строку целиком.** Ничего вместо неё писать не надо.

6. Внизу страницы нажми зелёную кнопку **Commit changes** → ещё раз **Commit changes**

Готово, страница открыта.

### Теперь то же самое для остальных пяти:

|---|---|---|
| 1 | `zapah-v-kvartire` | 5-я строка |
| 2 | `sredstva-ot-zapaha` | 4-я строка |

**Позиция строки чуть разная, но текст везде одинаковый** — ищи слово `noindex`.

⚠️ **Осторожно:** удаляй только строку со словом `robots`/`noindex`. Строки с `canonical`, `description`, `viewport` — не трогай.

# ШАГ 2. Заменить sitemap.xml

Я уже собрала новый файл — он лежит в воркспейсе как **`sitemap.xml`**. В нём 12 адресов вместо 6.

1. На GitHub в корне репозитория нажми на файл **`sitemap.xml`**
2. Карандашик (Edit)
3. **Выдели всё содержимое и удали**
4. Вставь содержимое моего файла `sitemap.xml`
5. **Commit changes**

*Либо проще:* Add file → Upload files → перетащи мой `sitemap.xml` → он заменит старый.

# ШАГ 5. Сказать Яндексу (самое важное!)

Без этого шага Яндекс узнает о переменах через недели. С ним — за дни.

Зайди в **Яндекс.Вебмастер** → выбери сайт **https://zapahstarosti.ru**

### 5.1 Переобход страниц
**Индексирование → Переобход страниц**
Вставь по одному адресу в строку:
```
https://zapahstarosti.ru/zapah-v-kvartire/
https://zapahstarosti.ru/sredstva-ot-zapaha/
https://zapahstarosti.ru/poroshok-dlya-tekstila/
https://zapahstarosti.ru/odezhda-i-tekstil/
https://zapahstarosti.ru/faq/
https://zapahstarosti.ru/kviz/
```
Нажми **Отправить**.

*Лимит обычно 20 страниц в день — шести хватит с запасом.*

### 5.2 Пересчитать sitemap
**Индексирование → Файлы Sitemap** → найди `sitemap.xml` → кнопка **«Пересчитать»**

# Если что-то пошло не так

**Страница пропала / сломалась вёрстка** — значит удалила лишнюю строку. На GitHub у файла есть кнопка **History**: открой предыдущую версию и восстанови.

**В коде всё ещё видно noindex** — браузер показывает старую версию. Нажми Ctrl+F5 (обновить без кэша) и подожди ещё пару минут.

**Вебмастер ругается «страница закрыта от индексирования»** — проверка была до твоей правки. Нажми переобход ещё раз через день.

## 1. Что было неверно в выводах от 04.11

**«Показов 273, кликов 8, CTR 2,9 %, позиция 9,4»** — эти цифры из интерфейса считались по трём месяцам. API даёт разбивку по месяцам:

| Месяц | Показов | Кликов | В день |
|---|---|---|---|
| Август (с 5-го) | 0 | 0 | 0 |
| Сентябрь | 52 | 1 | 1,7 |
| Октябрь | 199 | 6 | 6,4 |
| Ноябрь (1–3) | 29 | 2 | **9,7** |

**Рост показов в 5,7 раза за два месяца.** Прошлые отчёты этого не показывали, потому что скриншот давал только суммарную цифру.

**«Все клики — мусорные фразы»** — верно только для старых данных. За последние 28 дней клики: `/poroshok-dlya-tekstila/` 2, `/odezhda-i-tekstil/` 2, `/kviz/` 2, `/o-proekte/` 1.

**Оговорка:** во все 9 дней с кликами ровно по 1 клику. Похоже на собственные проверки позиций, а не на живых людей.

## 4. У трёх страниц снят noindex, но Google об этом не знает с 23 августа

| Страница | Что видит Google | Что на живом сайте 05.11 |
|---|---|---|
| `/zapah-v-kvartire/` | запрещено тегом noindex, обход 23.08 | meta robots НЕТ, canonical на себя |
| `/ventilyatsiya-i-vlazhnost/` | запрещено тегом noindex, обход 23.08 | meta robots НЕТ |
| `/sredstva-ot-zapaha/` | запрещено тегом noindex, обход 23.08 | meta robots НЕТ |

Noindex снят, но с 23.08 Google эти страницы не переобходил. Следствие: **у хаба «Квартира» ноль показов в Google**, и наш блок-каталог от 05.11 внутри него тоже невидим для поиска.

Причина не в ошибке сайта: нет внутренних ссылок, которые заставляли бы робота перечитать. У `/zapah-v-kvartire/` в теле ссылаются 11 страниц, но сам Google обходит 15.

## 9. Что делать — приоритет по факту, а не по гипотезам

1. **Ссылки на `/kogda-k-vrachu/`** — страница не существует для Google. Добавить из `/ubrat-zapah/`, `/kak-pogovorit-s-blizkim/`, `/faq/`. Самое дешёвое действие с гарантированным результатом.

3. **Сниппеты страниц топ-10 без кликов:** `/faq/` (поз. 2,4), `/lekarstva-i-zapah/` (3,7), `/kak-ubrat-zapah-v-stiralnoj-mashine/` (5,3), `/tonik-protirka/` (5,7), `/` (5,6).
4. **Матрас — не трогать до входа в топ-10.** Сейчас позиция 13,3, заголовок ни при чём.
5. **Запросы для планирования контента брать из Вордстата, а не из GSC** — здесь видно только 13 % показов.

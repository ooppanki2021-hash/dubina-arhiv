## Правила, чтобы не путать инструменты

1. **IndexNow — уведомление, не переобход.** 202 значит «приняли», а не «робот придёт».
2. **Пинговать только при реальном изменении содержимого.** Адаптивные картинки без правки текста —
   повод слабый; массовый пинг «на всякий случай» — шум.
3. **Порядок действий:** правка → `sitemap.xml` (`lastmod` только у изменённой страницы) →
   «Пересчитать sitemap» в Вебмастере → IndexNow на изменённые URL.
4. **Переобход (`POST /recrawl/queue`) — не для всего сайта.** 24–25 URL подряд дают пачку FAILED
   и жгут квоту. Точечно, по одной-две страницы, и только если обход в принципе идёт.
5. **«Пересчитать sitemap» через API недоступен.** Проверено: `GET` карты отдаёт статус,
   `POST` → 405, `/reindex` и `/refresh` → 404. Только кнопка в интерфейсе Вебмастера.
6. **Разбирать FAILED, а не повторять.** Причину видит только «Проверка ответа сервера» в интерфейсе.

## Что это значит для индексации

ИндексIndexNow-пинг не лечит главную проблему: с 22.10 по 04.11 Яндекс **не обходил сайт вообще**
(последний обход 04.10, все 24 заявки от 24.10 в FAILED). Причина — не сайт, а аварии дата-центров
Яндекса 8–11.10. Пока обход не восстановится, ни пинг, ни переобход ничего не ускорят.

## Что уточнить перед обзвоном

- **+7 (495) 118-35-48 повторяется у шести объектов** (Вороново, Сенеж, Домодедово, Химки, Митино, Слобода, Век жизни). Это общий номер сети lifepension.ru — прямыми контактами каждого пансионата он не является. Звонить можно, но спрашивать конкретный филиал по названию и адресу.
- **Телефон не указан у трёх объектов:** Сениор Групп, Заботливые руки, Центр заботы. Искать на сайте каждого.
- **У «Идиллии» сайт не указан** — в списке вместо него статья на vc.ru. Собственный сайт искать отдельно.
- **У «Заботы» второй номер 8-812 — петербургский.** Для московской службы он, скорее всего, ошибочный; проверить при первом звонке.
- **Пункты 6–10 (Домодедово, Химки, Митино, Слобода, Дзержинский)** названы по районам, без собственных имён. Это филиалы одной сети — при обзвоне уточнять точный адрес и название заведения, иначе разговор запутается.
- **Список не полный:** в подшаге приложения стояла цель 30 объектов, собрано 13. Добрать — из каталогов источника плюс реестр поставщиков социальных услуг региона (отдельный подшаг).
- **Цены — из каталогов, не из договоров.** Это ориентир «от», по которому заведение себя позиционирует; фактическая цена и условия ухода узнаются только при звонке.

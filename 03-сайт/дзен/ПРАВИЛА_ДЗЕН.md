# Дзен — правила и порядок работы (решения автора 06–07.10.2026)

Читать перед каждой статьёй для Дзена. Отсюда, а не из памяти чата.

## Порядок
1. Темы — из списка новых статей (шаг 5 приложения, вложение «Новые статьи — 9 тем»), по порядку. Не со старых страниц сайта.
2. Готовлю статью → показываю автору превью (`prosmotr_*.html`, в git не идёт).
3. После «да» — в приложение: подпункт «Дзен, статья N готова: …» в шаг 5 + текст и ссылки на картинки во вложение «Дзен — готовые статьи». Миграция addSubsV(N), кэш +1.
4. Публикует автор, через отложенную публикацию, 2–3 статьи в неделю.

## Текст
- Переработка, не копия сайта. Без бренда и продажи. Все запреты из `01_НАЧНИ_ОТСЮДА/ЗАПРЕТЫ_И_ГРАНИЦЫ.md` действуют.
- Конец: «Полная статья со всеми источниками сейчас на проверке. А пока — что уже есть на сайте:» + 2–3 ссылки на ПОДХОДЯЩИЕ по теме опубликованные страницы. Не отправлять всех на /chto-takoe-2-nonenal/.

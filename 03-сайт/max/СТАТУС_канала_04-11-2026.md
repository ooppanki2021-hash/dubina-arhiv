## Почему ленту не удалось посмотреть снаружи (04.11)

- `https://max.ru/id150302113710_biz` → **HTTP 404** без авторизации. Это ссылка на бизнес-профиль
  для кнопки «Написать», а не адрес канала; лента рендерится внутри приложения.
- API: `platform-api2.max.ru` (актуальный домен из ОФОРМЛЕНИЯ) без токена → ответа нет (000);
  `platform-api.max.ru` (старый) → 404. Токен бота в файлах не хранится — по правилу проекта.

**Вывод: статус постов 4, 5, 7–15 можно установить только по токену бота.**
Порядок: `GET /messages?chat_id=…&count=50` с заголовком `Authorization: <токен>`,
сопоставить с таблицей плана. Токен в чат, в файлы и в архив не записывать.

# 5. ПОРЯДОК РАБОТЫ

## Что Инна просила явно

1. **Резюме проекта — один файл навсегда.** Обновлять существующий. По прямому указанию 19.09 **файлы архива не удалять**: устаревшие разделы помечать историческими.
2. **Сначала обсудить, потом делать.** Показать варианты, дать выбрать.
3. **Спины упаковки** — делать по исходнику мыла, менять только строку применения и профильные слова.
4. **Логотип** брать с лицевой стороны коробки, менять **на всех спинах сразу**, чистая копия без «порванности».
5. Файлы к заливке отдавать **архивом с сохранением структуры папок** — Инна заливает через веб-интерфейс GitHub.
6. **Работать внимательно и последовательно, а не параллельно** (прямое указание 24.09.2026). Одно действие → проверка результата → следующее действие. Не запускать несколько правок, публикаций или проверок одновременно. Перед каждым шагом убедиться, что предыдущий завершён и дал ожидаемый результат (число замен, валидность разметки, совпадение live-версии). При ошибке — остановиться и разобраться, а не продолжать остальные шаги.
7. **Ничего не публиковать без одобрения** (24.09.2026): сначала «было → станет», публикация только после явного «да».

## Правило масштабирования

**Новый SKU только после окупаемости предыдущего.** Не печатать пять видов упаковки сразу.

## Правило текстов

**Страница не публикуется, пока не закрыты все пять букв AUDIO.** Объём наращивать только за счёт фактуры, которой нет у конкурентов. 450 слов по делу лучше 900 с водой.

## Разделение версий приложения

`03-сайт/сайт_текущий/app/` отражает публикацию, `05_приложение/app/` хранит более новую разработку. При обновлении архива новая версия и автономная копия сохранены. Не заменять их опубликованной старой версией, не менять личные данные, ключ `dubrava_dream_v1`, миграцию или отметки.

## Публикация не равна доказательству

Наличие фразы на сайте или PNG не делает её научно подтверждённой. Соблюдать ограничения по эффективности, температурным режимам, лекарствам и безопасности. Правки таких текстов на действующем сайте требуют отдельного согласования.

## Проект за минуту

**Проблема:** устойчивый запах может быть связан с кожей, текстилем, мебелью, влажностью и другими причинами. 2-ноненаль — одно из исследуемых соединений, а не объяснение любого запаха и не диагноз после 40 лет. Проблема также затрагивает достоинство человека и разговор с близкими.

**Два направления:** полезный информационный ресурс `zapahstarosti.ru` и будущая линейка «ДУБИНА 40+». Реклама и партнёрские ссылки — планы монетизации, не подтверждённый доход.

**Пять записанных формул:** синдет, гель, ролик, порошки для цветного и светлого. **Первый запуск — гель** (решение автора 24.09.2026; ранее — порошок для цветного). Влажные салфетки на танинах с ориентиром pH 5,2 и мыло для ног (26.09.2026) добавлены во вторую очередь, не как готовые рецептуры.

**Сырьё и производство:** промышленный замысел — закупаемый стандартизированный сухой экстракт и контрактная площадка. Полевой опыт в Осетии — история разработки, не утверждение о текущем ручном снабжении серии. Выбор завода, закупки и выпуск партии не подтверждены документами архива.

**Стадия:** сайт работает, рецептуры записаны, макеты есть. Промышленная пригодность, безопасность и заявленный эффект готовой продукции требуют подтверждения. Публичные фразы «производство идёт» или «закупаем» сами по себе не подтверждают договор, закупку или выпуск.

## Рабочий порядок с репозиторием сайта (правило 27.09.2026)

`zapahstarosti` — рабочий сайт на GitHub Pages. Правки вносятся **новым коммитом и обычным пушем**; откат чужих коммитов и force-push запрещены.

**Не держать рабочую копию сайта в workspace между шагами.** Workspace сохраняется снапшотом, и снапшот может восстановить старую версию `.git` и файлов: указатель откатывается на старый коммит (в ходе работ 27.09 это случалось трижды — на `255b46b`), после чего пуш отклоняется как не-fast-forward. Причина — не «старые коммиты мешают» (удалять историю нельзя и бесполезно), а восстановление старого снапшота; риск растёт, когда workspace тяжелее ~128 МБ.

| Ситуация | Что делать |
|---|---|
| Нужна правка на сайте | Клонировать `zapahstarosti` из GitHub во временную папку **вне** workspace (например `/tmp/site`), внести правку, закоммитить, запушить, клон удалить |
| Копия сайта уже лежит в workspace | `git fetch` → `git reset --hard` на удалённую ветку → правка → коммит → пуш, **одним командным блоком**, без паузы между шагами |
| Пуш отклонён («remote contains work») | Не повторять пуш и не форсить: fetch, выровнять базу, перенести свою правку поверх актуальной версии, запушить снова |
| Сайтом параллельно кто-то занимается | Не перетирать: сверить с GitHub, что уже исправлено, и доводить только остаток |
| Исходники картинок | Не хранить в workspace: опубликованные WebP уже в репозитории сайта и в архиве, лишний вес провоцирует откат снапшота |
| После пуша | Ждать ~2 минуты (сборка GitHub Pages) и проверять живую страницу; сразу после пуша возможен ложный 404 |

Между страницами делать паузу, не пушить два коммита залпом: два пуша подряд с интервалом в секунды когда-либо сорвали сборку Pages.

### Проверка живого сайта после правки

`verify_live.py` в корне workspace (рядом с `publish.py`). Вместо слепого ожидания сборки Pages опрашивает изменённую страницу и сравнивает с локальным файлом — возвращается, как только правка появилась:

```
python3 verify_live.py                        # страницы последнего коммита
python3 verify_live.py --commit fe44617..HEAD # за диапазон коммитов
python3 verify_live.py --all                  # все 29 страниц, раз в конце сессии
python3 verify_live.py --expect "фраза"       # ждать конкретную фразу
```

Проверять после каждой правки только её страницы, а полный обход делать один раз в конце сессии. Экономия на анализе пересечений: 26 страниц сверились за 1 секунду вместо ~54 минут слепых ожиданий.

### Проверка до коммита, а не после

`precommit.py` в корне workspace. Ловит порчу разметки **до** записи в историю — в задаче 38 первая попытка правки испортила файлы, и мусор уже попадал в коммит:

```
python3 precommit.py                        # страницы последнего коммита
python3 precommit.py --page faq/index.html  # одна страница
python3 precommit.py --since HEAD~3..HEAD   # за диапазон коммитов
```

Проверяет: целость парных тегов, один H1, дубли id, внутренние ссылки, наличие
картинок на диске, alt и loading, длину и уникальность title/description, а также
подозрительно маленький размер файла. Все 29 страниц сайта проходят без замечаний.
Служебные страницы (`/app/`) от контентных мета освобождены — это личный
планировщик за PIN, не контентная страница.

```

Исторические записи в `СВЕРКА` и согласованные переименования он не затирает. `--no-manifest` — только если манифест пересобирать не нужно.

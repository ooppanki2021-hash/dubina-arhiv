## Что больше не считать текущим заданием

- «Открыть 6 страниц», «20 страниц ещё закрыты», «переписать порошок с нуля как эталон» — исторические задания. Публикация 19.09 уже состоялась.

- Гранты — закрытая тема; ТЗ дизайнеру — на паузе.

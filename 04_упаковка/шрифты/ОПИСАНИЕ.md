# Шрифты упаковки

## Montserrat — 4 начертания

| Файл | Где используется |
|---|---|
| `Montserrat-Bold.ttf` | `logo_dubina.py`, `soap_face.py` |
| `Montserrat-Regular.ttf` | `logo_dubina.py`, `soap_face.py` |
| `Montserrat-Medium.ttf` | `soap_face.py` |
| `Montserrat-ExtraBold.ttf` | `soap_face.py` |

**Лицензия:** SIL Open Font License 1.1, текст в `Montserrat/OFL.txt`.
Распространение вместе с проектом лицензией разрешено; отдельно продавать
шрифт нельзя. Правообладатель — The Montserrat.Git Project Authors.

**Откуда взяты:** официальный репозиторий
`https://github.com/JulietaUla/Montserrat`, каталог `fonts/ttf/`, 03.10.2026.

**Зачем положены в архив.** Скрипты `logo_dubina.py` и `soap_face.py` брали шрифт
по жёсткому пути `/home/user/tools/fonts/Montserrat-*.ttf` — вне машины автора
их нельзя было запустить. Это единственные два скрипта, которые производят
**актуальные** макеты бренда `ДУБИНА_*`; остальные пять работают на DejaVu,
который есть в любой системе.

**Проверка подлинности версии.** Начертания подобраны не на глаз: с ними
пересобраны три архивных макета и сверены по SHA-256 —

| Макет | Результат |
|---|---|
| `ДУБИНА_логотип.png` (374 200 Б) | идентичен побайтово |
| `ДУБИНА_логотип_на_белом.png` (355 077 Б) | идентичен побайтово |
| `ДУБИНА_мыло_лицо.png` (1 392 763 Б) | идентичен побайтово |

То есть это та же версия шрифта, которой автор пользовалась изначально:
совпали не только размеры и картинка, а каждый байт, включая метаданные PNG.
При другой версии шрифта растеризация отличалась бы хотя бы в одном пикселе.

**Замена шрифта меняет макет.** Если когда-нибудь потребуется другая версия
Montserrat, пересобранные `ДУБИНА_*` перестанут совпадать с архивными —
это будет видно сразу при сверке.
